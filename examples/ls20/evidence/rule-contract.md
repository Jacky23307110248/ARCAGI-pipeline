# pseudo-LS20 M1 contract (Blueprint 0.4)

Rule truth: Tycho `ls20-9607627b`, source hash `67cc85888eeef68f125cbb5f5fb158e9ca455d6bca46b171790f556fcabf934e`. M0 Blueprint v0.4 is frozen. This package defines no layouts, generators, search, witnesses, or oracles.

## State and visibility

`State` holds pixel-grid position (5 px), shape/color/rotation, steps/initial steps/decrement, lives, level/status/action count, goal completion per goal, one ordered collider list, linked path cursors, pushers, pickup state, hint/fog settings, and separate coverage and win-dependency declarations. Player observations expose only game state and permitted feedback. Seeds, rule labels, coverage/dependency, private oracle state, and provenance do not enter observations.

## Transition contract

Directional input requests one 5px destination. Linked paths advance first. Then the runtime scans all sprites intersecting the destination in original sprite-list order. A wall blocks and terminates the scan. A goal compares the player's shape/color/rotation at action entry; a mismatch blocks player movement, sets feedback, does not end the sprite scan, and does not charge steps. Same-cell triggers can still advance after mismatch. Refill scanned before any later wall is collected, restores the level's initial counter, and exempts the action from decrement. A wall before refill ends scanning and the action pays its configured decrement. Effects already scanned are not undone by a later wall.

Successful movement records goal completion only at exact position and exact three-attribute match. All goals are required; order is unrestricted. Shape, color, and rotation entry triggers advance by one modulo 6, 4, and 4. Ordinary successful and wall-blocked direction actions pay configured decrement unless the action collected refill; mismatch actions pay no decrement. Counter value zero remains active; only a decrement below zero exhausts. Victory is checked before exhaustion, even if decrement would cross below zero.

On L1 only, when an ordered destination scan processes a shape/color/rotation trigger and the resulting player attributes match any unfinished goal, the trigger's match-hint callback causes Tycho to return after the scan and its movement/block outcome. Goal position is irrelevant to this callback. If the move is unblocked, the player is at the requested destination; if a later collider blocks it, the player stays at the prior position. Already processed destination effects remain applied. The return skips step decrement, pusher handling, goal completion, and exhaustion processing for the turn. Merely having matching attributes, or displaying transient feedback without this callback, does not exempt cost. L2–L7 do not use this early return. Each level initialization and explicit level RESET sets lives to 3. Exhaustion decrements life; before terminal game over it resets position, attributes, counter, pickup state, goals, and path to same-level initial values while preserving remaining lives. Third exhaustion enters GAME_OVER. Under Tycho wrapper policy `ONLY_RESET_LEVELS=true`, every RESET except from WIN resets the current level even at action count zero/GAME_OVER. RESET at WIN returns to campaign L1. Bare ARCBaseGame default is outside this contract.

Pushers are checked after the player reaches the requested destination and the single action counter charge. They use bounding-box overlap, not grid-point equality: Tycho assigns the pusher `BOUNDING_BOX`, then calls `Sprite.collides_with` against the moved player. For the 5px sprites, a 1px directional offset still contacts; the same adjacent boxes can also overlap one player grid position earlier. Pushers are kept in sprite-list order and the first contacting pusher is used. Its stop sampler starts one pixel in the push direction from its origin, then advances by the pusher width/height (5px here) for at most 11 samples; the first wall or goal stops it, and the carried distance is `sample_index - 1`. The player endpoint is the actual contact destination plus that many 5px cells, independent of the pusher's offset origin. Zero clear cells or no sampled wall/goal does not launch. A launch moves the pusher outward for 8 frames and back home for 6; the complete raw action has 17 frames for both one-cell and two-cell carries. It costs one action total. After the animation Tycho calls the ordered destination scan again at the player's carried endpoint: triggers and refill can therefore apply there. This second scan charges no extra action; a refill restores the initial counter. The pusher has already returned home when the synchronous action is observed.

A linked path and trigger collider have an explicit shared `path_id`. Hidden paths move before collision scanning, and their linked trigger sprite moves to the new path coordinate before destination collision checks. If the player move is blocked by a wall or mismatched goal, both path cursor/direction and linked trigger position roll back; level reset/death restores both to their initial positions. L6's closed mask turns around corners along its unique legal continuation.

Fog is render-only, strict visibility threshold distance >20 from player center (top-left +1.5). L1 match hint is visible only when current attributes match an unfinished goal; it is feedback, not instruction. Goal mismatch feedback and hint are transient five-rendered-frame cues that clear after their timer. Only the L1 trigger callback specified above changes turn processing; transient display by itself does not. Campaign wins advance in fixed order; L7 completion reaches terminal campaign state.

## Coverage and dependency

The M0 slot table remains authoritative. `mechanics_coverage_required` means mechanism present and interaction audited. `mechanics_win_dependency` means the valid win requires it. These fields remain distinct and neither is inferred from the other's contents.
